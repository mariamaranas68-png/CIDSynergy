CID SYNERGY — RESPONSIVE PUBLICATION WEBSITE PROTOTYPE

Open index.html in a modern browser to preview the website.

FEATURES
- Responsive homepage and navigation
- Feature stories with title, image, author, publication date, full story and photo caption
- Editorial cartooning gallery with title, image and message/explanation
- Simple in-browser CMS to add, edit and delete stories and cartoons
- Local browser storage for demo content
- Uses the supplied CID Synergy logo crop
- Green and yellow division-inspired palette, Poppins typography and rounded layouts

IMPORTANT LIMITATIONS
This is a front-end prototype, not a production CMS. Content is stored in the current browser using localStorage; it is not shared across devices or users. There is no login, server database, hosting, or access control. Before publishing publicly, connect it to a secure backend/CMS, configure authorized editor accounts, review all sample copy, and replace placeholder images with approved school photographs and original editorial cartoons. The sample image links require an internet connection. Poppins is loaded from Google Fonts when online.

QUICK START
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. Select “Admin CMS” or “Manage Publication” to manage demo content.
4. To reset sample content, clear this site's local storage in your browser.
